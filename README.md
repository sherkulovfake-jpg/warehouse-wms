# WAREHOUSE WMS — стартовый MVP

Веб-прототип WMS для РЦ «УХУД»: импорт группировки 1С, реестр рейсов, статусы, назначение сборщиков, мобильная отметка сборки, справочник товаров с весом/ячейкой, выработка, лотки и поддоны.

## Запуск
1. Установить Python 3.11+.
2. В папке проекта выполнить `python -m venv .venv`.
3. Активировать окружение и выполнить `pip install -r requirements.txt`.
4. Запустить `python seed_data.py` (создаст БД и перенесёт сотрудников/рейсы из приложенных файлов).
5. Запустить `python app.py`.
6. Открыть `http://localhost:5000`.

Для локальной сети: запустить на серверном компьютере и открыть `http://IP-СЕРВЕРА:5000` на телефонах и ПК в той же сети. Для реальной эксплуатации нужны HTTPS, резервные копии, отдельные учётные записи, аудит и тестирование на копии данных.

## Важные правила данных
- Повторный импорт обновляет строки товаров существующего рейса по паре дата+название, не сбрасывая статус и назначенного сборщика.
- Вес единицы хранится в справочнике товара в килограммах. Пока вес не заполнен, тоннаж по этой позиции не считается. Не следует автоматически считать вес из текста названия: это может быть масса упаковки, а не фактический вес брутто.
- Ставки в первой версии вынесены в настройки БД (0,79 для молока и 2,54 для хлеба), но расчёт выплат пока предварительный: до начисления нужно утвердить единицы ставки (руб./кг или иная база), правила округления и режим бригадной/индивидуальной выработки.
- В импортёре дата сейчас берётся как 22.10.2026 для приложенного тестового отчёта; для ежедневной работы следует использовать чтение периода из шапки отчёта. Это отмечено как следующий пункт интеграции.
- Документы клиентов сохраняются в структуре парсера, но отдельная таблица документов будет добавлена в следующей итерации.

## Что это
Это исходный код и рабочий стартовый прототип, а не размещённый в интернете промышленный сервис. До эксплуатации на реальном складе требуется пилот, проверка импорта на нескольких выгрузках 1С и согласование бизнес-правил.
